## 🚀 Flujo General del Proyecto

```
Planificación → Diseño → Desarrollo → WhatsApp → Dominio .cl → Hosting en la Nube → DNS → SSL → ¡En línea!
```

## ⏱️ Tiempo estimado total

| Etapa | Tiempo estimado |
|-------|----------------|
| Planificación y diseño | 1–2 días |
| Desarrollo de la página | 1–3 días |
| Compra del dominio .cl | 30 minutos |
| Configuración del hosting | 1–2 horas |
| Propagación del DNS | 24–48 horas |
| SSL y pruebas finales | 1–2 horas |
| **Total** | **~5–7 días** |

## 💰 Costos estimados (CLP)

| Ítem | Costo aproximado |
|------|-----------------|
| Dominio `.cl` (anual) | $15.000 – $25.000 CLP |
| Hosting básico (anual) | $0 – $60.000 CLP (ver opciones) |
| Certificado SSL | Gratuito (Let's Encrypt) |

> 📌 **Nota:** Existen opciones de hosting **gratuito** como GitHub Pages, Netlify o Vercel que son perfectas para páginas de presentación estáticas.

---

## 🛠️ Herramientas que usarás

- **Editor de código:** VS Code (gratuito)
- **Control de versiones:** Git + GitHub (gratuito)
- **Hosting:** Netlify / Vercel / GitHub Pages (gratuito)
- **Dominio .cl:** NIC Chile (registro oficial)
- **WhatsApp Business API:** Enlace directo (gratuito)
